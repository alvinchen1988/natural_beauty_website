# Natural Beauty Medical Clinic — HTML Design Prototype

Open `client-review.html` to review every proposed page, or open `index.html` for the homepage.

This is a local, build-free prototype. Each public-facing website page has its own HTML file. Shared styling and navigation are in `assets/css/styles.css` and `assets/js/site.js`.

Design direction:

- Editorial medical-luxury feel with deep forest green, warm ivory and restrained gold accents
- Large serif headings, generous spacing and rounded photographic frames
- Consistent consultation calls to action and dropdown navigation
- Clearly labeled placeholder images, ready to replace after client approval
- Responsive layouts for desktop, tablet and mobile

Notes:

- Contact details, clinic hours, booking destination and social links remain placeholders.
- The sample contact form is intentionally disabled and does not submit data.
- Hormone Replacement Therapy appears within the Perimenopause and Menopause Care page, not as a separate page.
